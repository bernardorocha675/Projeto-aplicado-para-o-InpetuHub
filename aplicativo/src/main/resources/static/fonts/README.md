# Fontes locais

Lato (pesos 400, 700 e 900) e Montserrat (700), arquivos latin normal WOFF2 das distribuições `@fontsource/lato` e `@fontsource/montserrat` 5.3.0. Pacotes obtidos do registro npm oficial com SHA-512 conferido contra `dist.integrity`. Licença OFL-1.1 em cada subpasta. Os arquivos acompanham o JAR para funcionar offline.

A escolha tipográfica foi feita pela referência visual das capturas fornecidas. A confirmação das fontes e do arquivo original da marca depende do acesso a https://inpetuhub.sites.ufsc.br/agenda/; não foi declarada equivalência exata.
