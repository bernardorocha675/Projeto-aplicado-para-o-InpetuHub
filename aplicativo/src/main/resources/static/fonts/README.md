# Fontes

Lato (Łukasz Dziedzic) e Plus Jakarta Sans (Tokotype), ambas sob a SIL Open Font License 1.1. São as fontes do site oficial do InPETU Hub, copiadas do Google Fonts (subconjunto latin, woff2) para funcionar sem internet. Plus Jakarta Sans é uma fonte variável: um arquivo cobre os pesos 600–800.
