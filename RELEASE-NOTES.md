# InPETU Hub 0.5.9

Agenda mais legível.

- **Agenda com contraste adequado.** A faixa da agenda passou para o azul oficial do InPETU Hub, e os textos cinza ficaram um pouco mais escuros. Agora tudo fica legível também para quem enxerga pouco (padrão WCAG AA). O título segue as medidas da agenda do site oficial.
- **Setas do mês maiores.** As setas para trocar o mês ficaram com 44 px, mais fáceis de tocar no celular.
- **Pular para o conteúdo.** Quem navega pelo teclado tem, no primeiro Tab de qualquer tela, um link que pula o menu e vai direto ao conteúdo.
- **Cabeçalho branco e azul oficial.** O cabeçalho ficou branco, e links e botões de todo o sistema usam o azul oficial do site, com o cinza mais escuro.

Dados, reservas, contas, configurações, chave e backups permanecem na mesma pasta (`InPETU-Hub/0.4`); quem está na 0.5.x ou na 0.4.17 recebe esta versão automaticamente, com backup antes da troca. Sem migration nem reset. Windows/macOS/Linux x64/ARM64 e Java privado preservados. No macOS, o iniciador continua exigindo macOS 13 ou mais recente.

Publicação condicionada à matriz obrigatória de RELEASES.md.
