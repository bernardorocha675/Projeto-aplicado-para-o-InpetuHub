# InPETU Hub 0.5.2

Atualização mais fácil quando o iniciador antigo continua aberto.

- **Configurar / atualizar sempre tenta de novo.** Antes, se uma atualização falhasse, o botão só avisava que ela seria tentada na próxima abertura, até o iniciador ser fechado.
- **O executável baixado atualiza sozinho.** Ao abrir o pacote de uma versão mais nova que a instalada, o iniciador instala a partir dele mesmo, sem baixar de novo da internet. Antes da troca, os dados recebem o backup de sempre.
- **O executável novo assume o lugar do antigo.** Fechar a aba do navegador não fecha o iniciador. Se um iniciador mais antigo ficou aberto com o sistema parado, abrir o executável novo fecha o antigo e continua com a versão nova. Com o sistema em uso, nada é interrompido e a tela aberta é mostrada.

O visual do site oficial, a agenda e a área interna continuam iguais aos da 0.5.1. Dados, reservas, contas, configurações, chave e backups permanecem na mesma pasta (`InPETU-Hub/0.4`); quem está na 0.5.x ou na 0.4.17 recebe esta versão automaticamente. Não há migration, reset ou mudança de dependências. Windows/macOS/Linux x64/ARM64 e Java privado preservados. No macOS, o iniciador continua exigindo macOS 13 ou mais recente.

Publicação condicionada à matriz obrigatória de RELEASES.md.
