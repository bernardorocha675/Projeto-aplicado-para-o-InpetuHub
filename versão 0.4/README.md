# InPETU Hub — versão 0.4

Aplicativo de agenda e gestão de reservas com um iniciador para **Windows, macOS e Linux**. O pacote inclui o aplicativo e seu Java privado. Não é necessário instalar VS Code, Java ou Maven para usar a release.

Baixe o pacote do seu sistema em [Releases](https://github.com/bernardorocha675/Projeto-aplicado-para-o-InpetuHub/releases), extraia e abra o iniciador. A tela prepara a instalação e oferece **Iniciar**, **Parar** e **Configurar / atualizar**. As correções **0.4.x** são verificadas antes de iniciar; o banco e as configurações permanecem no computador.

A 0.4 cria um banco novo no perfil do usuário. Não apaga nem importa automaticamente a instalação da 0.3. A estrutura e as regras de reservas continuam baseadas nas mesmas migrations V1–V4. Cadastros e reservas começam vazios; referências de configuração e as cinco contas são criadas automaticamente.
